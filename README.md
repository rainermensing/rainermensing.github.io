# Rainer Mensing — CV

A responsive, print-friendly CV published as a static GitHub Pages site.

## Preview locally

Open `index.html` in a browser. The site has no build step or runtime dependencies.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and deploy from the root of the `main` branch. The static HTML, CSS, and SVG files are ready to serve as-is.

## Content and logo marks

The CV content is based on the supplied source. Organization and technology marks are lightweight, accessible text-based treatments; the adjacent names remain visible if styling is unavailable.
